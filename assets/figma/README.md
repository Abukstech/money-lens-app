# Money Lens design assets

Original artwork exported from the user-supplied Money Lens Figma file on 2026-10-25. Assets are bundled locally. Artwork is not redrawn. Transparent artwork is exported with `contentsOnly: true` and sRGB colors to exclude inherited canvas backgrounds. Original image crop transforms are retained in the onboarding screen. Device status bars and home indicators are provided by the operating system. The profile photograph appears only in the explicitly labelled sample-data preview; it is not assigned to real users.

Source: https://www.figma.com/design/5QtCax5pSzacafM8l464qp/Money-Lens
