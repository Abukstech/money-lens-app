# Aeonik preview fonts

These files are the user's local Aeonik Pro **Trial** fonts from Downloads/aeonik-pro-trial, copied without alteration. They are used for the local design preview.

- Aeonik-Regular.otf → aeonikprotrial-regular.otf
- Aeonik-Bold.otf → aeonikprotrial-bold.otf
- Aeonik-Light.otf → aeonikprotrial-light.otf

Replace these trial files with appropriately licensed Aeonik app/web font files before publishing or distributing a release. No production license was supplied with these files.

The current set has no Medium or Italic face. The shared medium token uses Regular; the italic/emphasis token uses Bold without synthesizing a different font. The supplied Money Story title and Money Lens wordmark are image assets and remain unchanged.
